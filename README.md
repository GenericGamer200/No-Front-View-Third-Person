# No Front View Third Person

---

## summary

this mod aim to skip the front view in third person mode

## logic

if player in third person and press the change perspective button. it will force them to enter the first person, skipping the front view

## note

This mod is built specifically for Minecraft **1.20.1** on the **Forge** loader

If you are using Fabric or a different game version, consider checking out **Disable Front Perspective** by _RealMyzael_
